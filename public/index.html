Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target. You may assume that each input would have exactly one solution, and you may not use the same element twice.

Mistake Detected: Self-Pairing Bug

When target = 6 and nums = [3, 2, 4], using the same element index twice returns [0, 0] instead of distinct indices [1, 2].

Recommended fix: Ensure that the checked complement index is not equal to the current index, or insert elements into the hash map only after checking.
PROBLEM UNDERSTANDING

Task Scope & Core Invariants

What It Asks:

Find two distinct indices in the array whose elements sum to target.

Input & Output:

Input: nums: int[], target: int. Output: [index1, index2].

Constraints & Scale:

2 ≤ nums.length ≤ 10⁴, -10⁹ ≤ nums[i], target ≤ 10⁹. Exactly one valid answer exists.

Key Algorithmic Observation:

For each element x, the required partner is uniquely determined as (target - x), enabling single-pass hash lookups.

Time Complexity O(n) Single linear pass through the array
Space Complexity O(n) Auxiliary hash table storing up to n elements
Auxiliary Space O(n) Extra allocated memory excluding input array
Total Space O(n) Input buffer plus auxiliary hash map

EDUCATIONAL ANALYSIS

Algorithm Analysis & Logic

The solution uses an auxiliary hash map (seen) to keep track of previous array elements and their respective indices in single pass.

For each element num, we determine the required difference target - num. If this complement was already observed, we have immediately discovered the unique pair whose sum equals the target.

BASELINE BENCHMARK

Brute Force Baseline

Exhaustive O(n²) Time O(1) Space Not Run

Iterate through every element i, then iterate through all elements j > i to check if nums[i] + nums[j] == target. While easy to formulate, this scales quadratically and causes Time Limit Exceeded on large inputs. 

class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []

OPTIMAL SOLUTION

Optimal Solution

Two Pointers O(n) Time O(1) Aux Space Not Run 
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen = {}
        for i, num in enumerate(nums):
            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i
        return []

KEY TAKEAWAYS & CONCEPTS

DSA Principles to Remember

  • ✓ Space-Time Tradeoff: Trading O(n) memory in a hash map drops time complexity from O(n²) to O(n).
  • ✓ Complement Formula: Look up target - current to verify pairs in constant O(1) time.
  • ✓ Self-Pairing Avoidance: Query the map before storing the current element to prevent using the same index twice.
